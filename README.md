# DevForge - Developer Tool Suite

A collection of 10 free, privacy-first developer tools. All client-side, no backend, no signup needed.

## Tools

| Tool | Description |
|------|-------------|
| [JSON → TypeScript](https://bshes.github.io/json2ts/json2ts/) | Convert JSON to TypeScript interfaces/types |
| [CSV ↔ JSON](https://bshes.github.io/json2ts/csv2json/) | Bidirectional CSV/JSON conversion |
| [Regex Tester](https://bshes.github.io/json2ts/regex/) | Live regex testing with replace |
| [Base64 Encoder/Decoder](https://bshes.github.io/json2ts/base64/) | Base64 encode/decode with Unicode support |
| [JWT Decoder](https://bshes.github.io/json2ts/jwt/) | Decode JWT tokens without verification |
| [SQL Formatter](https://bshes.github.io/json2ts/sql-formatter/) | Format and beautify SQL queries |
| [Diff Checker](https://bshes.github.io/json2ts/diff/) | Side-by-side text comparison |
| [UUID Generator](https://bshes.github.io/json2ts/uuid/) | Generate UUID v4/v1 in bulk |
| [Timestamp Converter](https://bshes.github.io/json2ts/timestamp/) | Convert Unix timestamps to dates |
| [Color Converter](https://bshes.github.io/json2ts/color/) | Convert HEX/RGB/HSL/CMYK |

## Tech Stack

- Pure HTML/CSS/JS — zero frameworks, zero dependencies
- GitHub Pages hosting — free, fast, global CDN
- All processing happens in your browser — no data leaves your machine
